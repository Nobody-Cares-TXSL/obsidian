# Lesson 13: What colour is Anna's hat?
> https://nce.luzhenhua.cn/lesson.html#NCE1/013&014－A%20New%20Dress

## 原文

What colour's your new dress?

It's green.

Come upstairs and see it.

Thank you.

Look! Here it is!

That's a nice dress. It's very smart.

My hat's new, too.

What colour is it?

It's the same colour. It's green, too.

That is a lovely hat!

## 句型结构

### What colour's your [noun]?

> 结构：**What colour's**（What colour is 的缩写）+ **your** + **[名词]**，询问物品颜色。

- `colour's` = `colour is`，缩写规则同 [[Lesson 7 - Are you a teacher]] 的 be 动词缩写
- 回答：`It's green/red/blue.`
- 美式拼写为 `What color's...`

### Come [verb] and [verb].

> **祈使句** + and 连接两个动作，表示"做某事然后做某事"。

- 祈使句省略主语 you，动词用原形：`Come`、`Look`
- and 连接：`Come upstairs and see it.`（上楼来看看）
- `Look!` 也是祈使句，表示"看！"

**注意**：祈使句不是疑问句也不是陈述句，动词直接开头，不加 do/does

---

## 语法要点

### 祈使句

> 省略主语 you，动词用原形开头的句式，用于命令、请求或建议。

- 肯定祈使句：`Come upstairs.` / `Look!` / `Catch!`
- 否定祈使句：`Don't look.`（加 Don't）
- 常见场景：指路（`Turn left.`）、请求（`Come and see.`）、提醒（`Look!`）

### the same + noun

> `the same` + 名词，表示"同样的……"。

- `It's the same colour.` = `It's green, too.`
- `the same` 必须加 **the**，不能说 "It's same colour."

### Here it is! vs Here is...

> [[Lesson 3 - Sorry, sir.]] 讲了 `Here is + 名词`，本课补充**代词**作主语时的语序。

- 名词作主语：`Here is my ticket.`（倒装）
- 代词作主语：`Here it is.`（不倒装，it 在 is 前面）

**注意**：代词（it/they）永远不倒装 — `Here it is`✓ / `Here is it`✗

## 语义分析

### Come upstairs and see it.

**结构手术**：
- **Come** → 祈使动词（谁来做？）→ [无主语，动词原形开头] → 省略主语 you，发出邀请/命令
- **upstairs** → 地点副词（去哪？）→ [无介词直接跟在动词后] → 上楼
- **and** → 并列连词（两个动作什么关系？）→ [连接 come 和 see 两个动词] → "来做 A，然后做 B"，and 起顺承作用
- **see it** → 动词 + 宾语代词（看什么？）→ [it 位于 see 之后] → 看看它（指代前面的 dress）

**词义还原**：
- **see**：此处不是"看见"（被动感知），而是"去看一看"（主动行为），是 invite sb to look 的意思。
- **upstairs**：副词作状语，不需要加介词 to，直接跟在动词后表示方向。

**直译复盘**：来楼上并且看它。（"并且看它"在中文里听起来像任务清单，缺乏邀请的语气。）

**意译重组**：上来看看吧。把"and see it"合并为一个自然的动作"来看看"，省略"it"，因为上下文已明确。

**翻译公式**：祈使句 + and + 动词 → "来/去 + 动词 + 吧"（中文常将 and 后的动词合并为连动结构，省略并列连词）。

### Here it is!

**结构手术**：
- **Here** → 地点副词（在哪？）→ [句首位置] → 在这儿
- **it** → 代词主语（什么？）→ [位于 Here 之后、is 之前] → 指代上文提到的 dress
- **is** → 系动词 → [跟在主语 it 之后] → 存在/就是

**词义还原**：
- **Here it is** vs **Here is it**：英语中地点副词开头的倒装句，若主语是名词则倒装（Here is the book），若主语是代词则不倒装（Here it is）。这是英语的一条硬性规则。

**直译复盘**：这里它就是。（语序和中文完全相反，中文会说"它就在这儿"。）

**意译重组**：在这儿呢！把系动词 is 转化为语气词"呢"，把 Here 从句首挪到句末"在……这儿"。

**翻译公式**：Here + 代词 + be → "在 + 地点 + 呢！"（中文用"呢"体现 Here it is 的展示语气；代词不倒装 → 中文不改变语序，直接说"它在这儿"。）

### My hat's new, too.

**结构手术**：
- **My hat's** → 主语 + 系动词（谁的什么？）→ [所有格 My + 名词 hat + 's(=is)] → 我的帽子是
- **new** → 形容词表语（怎么样？）→ [位于系动词 is 之后] → 新的
- **too** → 副词（还有呢？）→ [位于句末，逗号隔开] → 也

**词义还原**：
- **hat's**：`hat is` 的缩写，注意不是 hat has。在新概念初级阶段，'s 大多缩写 is，判断依据是后面跟的是形容词 new（形容词只能作表语，需系动词连接），而不是过去分词。

**直译复盘**：我的帽子是新的，也。（"也"放在句末在中文里不自然，中文说"我的帽子也是新的"。）

**意译重组**：我的帽子也是新的。把"too"从句末挪到"是"字前面，译为"也是"。

**翻译公式**：... , too → "……也是……"（中文将 too 放在动词/系动词之前，而非句末。）

### It's the same colour.

**结构手术**：
- **It's** → 主语 + 系动词 → [代词 It + is] → 它是
- **the same** → 固定形容词短语（什么样的？）→ [the + same 修饰 colour] → 同样的
- **colour** → 名词表语（是什么？）→ [位于系动词之后] → 颜色

**词义还原**：
- **same**：本身是形容词，但在英语中必须与定冠词 the 连用（the same），不能单独说 same colour。这是因为 same 源自古英语同一个词根，隐含"特指那个已提到的"，所以需要 the。

**直译复盘**：它是这个相同的颜色。（"这个相同的"在中文里冗余，中文直接说"同样的颜色"。）

**意译重组**：是同样的颜色。省略主语"它"，将"the same colour"整体译为"同样的颜色"。

**翻译公式**：the same + 名词 → "同样的 + 名词"（中文不需要冠词，直接将 the same 译为"同样的"修饰名词。）
