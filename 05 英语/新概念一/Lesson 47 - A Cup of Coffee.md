# Lesson 47: How does Ann like her coffee?

Do you like coffee, Ann?

Yes, I do.

No, thank you.

I don't like milk in my coffee.

I like black coffee.

## 句型结构

### "Do you like + 名词?" — 询问喜好

> 用助动词 Do + 主语 + like 询问对方是否喜欢某物，回答用 do/don't

- `Do you like coffee, Ann?` — 你喜欢咖啡吗，安？
- 肯定回答：`Yes, I do.`（不能用 ~~Yes, I like.~~）
- 否定回答：`No, I don't.`
- like 后面直接接名词，不需要介词（~~like to coffee~~）

### "Do you want + 名词?" — 询问意愿

> 用助动词 Do + 主语 + want 询问对方是否想要某物，回答用 please/thank you

- `Do you want a cup?` — 你想来一杯吗？
- `Do you want any sugar?` — 要加糖吗？
- 肯定回答：`Yes, please.`（比 "Yes, I do." 更礼貌）
- 否定回答：`No, thank you.`
- like 表一般偏好（喜欢），want 表当下需求（想要）

## 语法要点

### 助动词 do — 构成实义动词的疑问句和否定句

> 英语中实义动词（如 like, want）不能像 be 动词那样直接倒装构成疑问，需要借助于助动词 do

- 疑问句：`Do + 主语 + 动词原形 + ...?`
  - `Do you like coffee?`（不能用 ~~You like coffee?~~）
  - `Do you want any sugar?`
- 否定句：`主语 + don't + 动词原形 + ...`
  - `I don't like milk in my coffee.`
- do 在此无实际词义，纯粹起语法辅助作用

**注意**：do 后面的动词必须用原形，不能用 ~~Do you likes~~ 或 ~~I don't wants~~

## 语义分析

### Do you like coffee, Ann?

**结构手术**：

- **Do** → 助动词（什么功能？）→ [位于句首，在主语 you 之前，标志这是一般疑问句。Do 本身无词义，纯粹起语法辅助作用——帮助实义动词 like 构成疑问句，因为英语中实义动词不能像 be 动词那样直接倒装] → （无实际词义，辅助构成疑问）
- **you** → 人称代词，作主语（谁？）→ [放在助动词 Do 和实义动词 like 之间] → 你
- **like** → 实义动词，作谓语（做什么？）→ [在主语 you 之后，后面接名词宾语 coffee。因为是助动词 Do 帮忙构成疑问，所以 like 保持原形，不需要变形] → 喜欢
- **coffee** → 不可数名词，作宾语（喜欢什么？）→ [跟在动词 like 后面，是动作的承受者] → 咖啡
- **Ann** → 专有名词，作呼语（叫谁？）→ [放在句末，用逗号隔开，不参与语法结构，仅标明说话对象] → 安

整体结构：这是 **Do 引导的一般疑问句**，结构为 `Do + 主语 + 动词原形 + 宾语 + ...?`。与 be 动词疑问句（如 "Are you a teacher?"）不同，实义动词（like, want, play 等）需要借助助动词 Do 来构成疑问。Do 在这里是一个"语法工具人"——它不携带任何语义，只是因为英语语法规定"实义动词不能自己跑到句首"。

**词义还原**：
- **Do**：助动词，在此无实际含义。不要将它与实义动词 do（做）混淆——这里的 Do 只是一个语法标记，等价于中文里把句尾的"吗"移到句首的语序调整操作。Do 也可以帮助构成否定句（don't）。
- **like**：实义动词，"喜欢"。注意 like 后面直接接名词宾语（like coffee），不需要加介词 to（~~like to coffee~~）。这与 want 的用法一致。

**直译复盘**：（助动词无义）你 喜欢 咖啡，安？（中文直接在句末加"吗"就行，不需要在句首加任何助词，英文的 Do 在中文里找不到对应词，"很怪"。）

**意译重组**：你喜欢咖啡吗，安？「去掉句首的助动词 Do（中文不需要）；在句末加"吗"构成疑问；保持语序不变——中文和英文的主谓宾语序一致（你-喜欢-咖啡），区别仅在于英文用 Do 提到句首，中文用"吗"放在句尾」。中英文构成疑问句的方式不同：英文是"句首加助动词"，中文是"句尾加疑问语气词"。

**翻译公式**：Do 引导的一般疑问句翻译时，**去掉助动词 Do**，在句末加"吗"即可：`Do you like X? → 你喜欢 X 吗？`。英文靠句首的 Do 标记疑问，中文靠句尾的"吗"标记疑问——一个在前，一个在后，功能等价。

### I don't like milk in my coffee.

**结构手术**：

- **I** → 人称代词，作主语（谁？）→ [放在否定助动词 don't 之前] → 我
- **don't (do not)** → 否定助动词（什么功能？）→ [在主语 I 之后、实义动词 like 之前。don't = do + not，助动词 do 的否定形式。与肯定句的疑问句用 Do 一样，这里的 do 纯粹帮助实义动词 like 构成否定] → 不
- **like** → 实义动词，作谓语（做什么？）→ [在 don't 之后保持原形。因为否定由 don't 承担，like 不需要任何变形] → 喜欢
- **milk** → 不可数名词，作宾语（不喜欢什么？）→ [跟在 like 后面] → 牛奶
- **in my coffee** → 介词短语，作后置定语（哪里的牛奶？）→ [介词 in（在……里）+ 所有格形容词 my（我的）+ 名词 coffee（咖啡），放在 milk 后面修饰它。这里 in 不是空间方位"里面"，而是表示"添加到/混合在"的引申义——"加在咖啡里的牛奶"] → （加在）咖啡里的

整体结构：这是 **don't 引导的否定句**，结构为 `主语 + don't + 动词原形 + 宾语 + 介词短语`。关键语义难点在 "milk in my coffee"——这里的 in 不是描述牛奶的物理位置（"在咖啡里面"），而是描述一种**添加关系**（"加在咖啡里的"）。中文翻译时需要将这种"添加"的隐含语义显化出来。

**词义还原**：
- **don't**：do not 的缩写，否定助动词。与肯定句中的 Do 一样，don't 在此无实际词义，只是一个语法工具——它告诉读者"后面的动词要取反"。中文里不需要这种工具，直接在动词前加"不"就行（不喜欢）。
- **in**：介词，本义"在……里面"。但在此句中，in 从空间方位引申为**配料/添加关系**——"milk in my coffee" 不是指牛奶已经物理地"在"咖啡里，而是指"（加在）咖啡里的牛奶"。类似的用法："sugar in tea"（茶里的糖）、"cream in soup"（汤里的奶油）。

**直译复盘**：我 不喜欢 牛奶 在我的咖啡里。（"牛奶在我的咖啡里"听起来像是在描述牛奶的物理位置，而不是在说不想要加牛奶的偏好，"很怪"。）

**意译重组**：我不喜欢在咖啡里加牛奶。「把后置定语 "in my coffee" 从名词 milk 后面挪到动词 like 前面，形成"在咖啡里加牛奶"的动宾短语——中文更习惯用"在……里加……"的主动结构来表达添加关系，而不是用"在……里的牛奶"这种被动定语；将 "milk in my coffee" 从静态的位置描述转化为动态的"加牛奶"动作描述」。中文表达"不喜欢某种配料"时，习惯说"不喜欢在 X 里加 Y"，而不是"不喜欢 Y in X"——前者是动态的动作描述，后者是静态的位置描述。

**翻译公式**：当英文用 `名词 + in + 容器` 表达"容器里的添加物"时，中文将 in 介词短语**转化为"在 + 容器 + 里 + 加 + 名词"的动宾结构**：`I don't like Y in X → 我不喜欢在 X 里加 Y`。英文用静态方位（in）描述配料关系，中文用动态动作（加）描述同样的语义。

### Do you want any sugar?

**结构手术**：

- **Do** → 助动词（什么功能？）→ [位于句首，帮助实义动词 want 构成疑问] → （无实际词义）
- **you** → 人称代词，作主语（谁？）→ [在 Do 和 want 之间] → 你
- **want** → 实义动词，作谓语（做什么？）→ [保持原形，表示"想要、需要"] → 想要
- **any** → 限定词（多少？）→ [修饰不可数名词 sugar，在疑问句中用 any 表示"一些"。any 在疑问句和否定句中弱化为"一些"的含义] → 一些
- **sugar** → 不可数名词，作宾语（想要什么？）→ [跟在 want 后面，是动作的承受者] → 糖

整体结构：同样是 **Do 引导的一般疑问句**，与 "Do you like coffee?" 结构相同。关键区别在于 **any 的使用**——疑问句中用 any（而非 some）来表示"一些"。这在 [[Lesson 43 - Hurry Up]] 中已学过（Is there any water?），这里扩展到了 Do you want 疑问句中。any 的作用域覆盖了疑问句——当你不确定对方是否想要时，用 any 表示开放性的"是否存在一些"。

**词义还原**：
- **want**：实义动词，"想要、需要"。注意 want 与 like 的区别：like 表示长期的、一般性的偏好（"我喜欢咖啡"），want 表示当下具体的、一次性的需求（"现在想来一杯吗"）。在服务场景中，"Do you want...?" 比 "Do you like...?" 更直接地表达"我现在提供给你，你要不要"。
- **any**：限定词，在疑问句中表示"一些"。与 some 的区别：some 用于肯定句（There are some cups），any 用于疑问句和否定句。但中文里不区分——都译为"一些"或直接省略。

**直译复盘**：（助动词无义）你 想要 一些 糖？（"一些糖"在中文里听起来量级不太对——中文更习惯说"要加糖吗"，把"一些"省略，"很怪"。）

**意译重组**：要加糖吗？「去掉助动词 Do；将 "want any sugar" 从字面的"想要一些糖"转化为中文更自然的"加糖"——中文在提供食物/饮料时的常用说法是"要加 X 吗？"而不是"你想要一些 X 吗？"；省略 any 的"一些"含义，因为中文疑问句本身已包含"是否需要"的开放性」。中文提供服务时的提问更简洁——直接说"要加 X 吗？"，比英文的 "Do you want any X?" 更短。

**翻译公式**：在提供食物/饮料的服务场景中，`Do you want any X?` 可以简化翻译为 `要加 X 吗？`，省略主语和 any——中文服务用语比英文更简洁，直接用"要……吗？"替代完整的疑问句结构。
