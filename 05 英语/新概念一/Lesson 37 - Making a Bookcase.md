# Lesson 37: What is Susan's favourite colour?
> https://nce.luzhenhua.cn/lesson.html#NCE1/037&038－Making%20a%20Bookcase

## 原文

You're working hard, George.

What are you doing?

I'm making a bookcase.

Give me that hammer please, Dan.

Which hammer?

This one?

No, not that one.

The big one.

Here you are.

Thanks, Dan.

What are you going to do now, George?

I'm going to paint it.

What colour are you going to paint it?

I'm going to paint it pink.

Pink!

This bookcase isn't for me.

It's for my daughter, Susan.

Pink's her favourite colour.

## 句型结构

### "be going to" — 将来时结构

> 表达已经决定的计划或意图，结构：主语 + am/is/are going to + 动词原形

- `I'm going to paint it.` — 我打算给它刷漆
- `What are you going to do now?` — 你现在打算做什么？
- `What colour are you going to paint it?` — 你打算把它涂成什么颜色？
- 疑问句：What + be + 主语 + going to + 动词原形?

**注意**：going to 后接动词原形（paint），不是 -ing 形式（~~painting~~）

## 语义分析

### You're working hard, George.

**结构手术**：
- **You** → 主语（代词）→ [句首，动作执行者] → 你
- **'re (are)** → 谓语（be 动词）→ [与 you 搭配，构成现在进行时] → 正在
- **working** → 实义动词现在分词 → [are 之后，与 be 构成进行时] → 工作
- **hard** → 状语（副词）→ [在动词 working 之后，修饰动词的方式/程度] → 努力地、辛苦地
- **George** → 呼语（vocative）→ [句末，用逗号隔开，直接称呼对方] → 乔治

**词义还原**：
- **hard**：此处是副词，修饰动词 working，表示"努力地、卖力地"。注意 hard 既是形容词（`a hard question` — 困难的）也是副词（`work hard` — 努力工作），且形容词和副词形式相同（不是 ~~hardly~~，hardly 意为"几乎不"，含义完全不同）。

**直译复盘**：你正在工作努力地，乔治。（中文副词通常在动词前面，"工作努力地"语序颠倒，且"工作"和"努力地"的搭配不如"努力工作"自然，"很怪"。）

**意译重组**：你工作得很努力，乔治。——「把副词 hard 从动词 working 之后挪到前面，变为"努力 + 工作"；将 working hard 整体重组为"工作得很努力"，用"得"字连接动词和程度补语；呼语 George 保留在句末。」

**翻译公式**：`主语 + be + doing + 副词, 呼语` → "主语 + 副词 + 动词 + 得 + 程度补语, 呼语"，英文后置的程度副词在中文中需前置到动词前，或用"得"字结构后置。

### Give me that hammer please, Dan.

**结构手术**：
- **Give** → 谓语动词（祈使句省略主语 you）→ [句首动词开头，祈使句标志] → 给
- **me** → 间接宾语（宾格代词）→ [动词后第一个宾语，动作的接受者] → 我
- **that hammer** → 直接宾语（名词短语）→ [动词后第二个宾语，被传递的具体物品] → 那把锤子
- **please** → 客气标记（副词）→ [句中偏后位置，使祈使句变得礼貌] → 请
- **Dan** → 呼语（vocative）→ [句末，逗号隔开，称呼对方] → 丹

**词义还原**：
- **please**：源自 `if it pleases you` 的缩略，作为礼貌标记附加在祈使句中，使命令语气变得委婉。please 可前置（`Please give me...`）也可后置（`Give me... please`），后置时语气稍显随意。
- **Give me**：双宾语结构，give 后接"人 + 物"（间接宾语 + 直接宾语），也可改为 `Give that hammer to me`（直接宾语 + to + 间接宾语）。

**直译复盘**：给 我 那把锤子 请，丹。（中文"给"后面直接跟"请"读不通，语序别扭，"很怪"。）

**意译重组**：请把那把锤子递给我，丹。——「把 please 从句中位置挪到句首变为"请"；把间接宾语"me"和直接宾语"that hammer"的位置对调，并用"把"字句引出直接宾语"把那把锤子"；"give"在中文递物场景中译为"递给"更地道。」

**翻译公式**：`Give + 人 + 物 + please, 呼语` → "请把 + 物 + 递/交给 + 人, 呼语"，英文双宾语结构在中文中常转换为"把"字句，please 移至句首。

### I'm going to paint it pink.

**结构手术**：
- **I** → 主语 → [句首，动作执行者] → 我
- **'m (am)** → 谓语（be 动词）→ [与 I 搭配，构成 be going to 将来时] → 打算
- **going to** → 将来时标记（固定结构）→ [be 动词后，后接动词原形，表示已决定的计划] → 将要
- **paint** → 实义动词（原形）→ [going to 之后，接动词原形] → 涂漆
- **it** → 宾语（代词）→ [动词 paint 之后，动作的承受者，指代 bookcase] → 它
- **pink** → 宾语补足语（形容词）→ [宾语 it 之后，补充说明宾语被涂成的结果/颜色] → 粉色

**词义还原**：
- **paint it pink**：这是"动词 + 宾语 + 宾补"结构（S + V + O + C）。pink 不是名词"粉色"，而是形容词"粉色的"，作为宾语补足语说明涂漆的结果——把"它"涂成"粉色的"。类似的还有 `paint the door red`（把门涂成红色）。
- **going to**：表示已经做好的打算或计划，不是临时起意。与 will（单纯将来）不同，going to 带有"意图"的语义色彩。

**直译复盘**：我打算涂漆它粉色。（中文"涂漆它粉色"不通顺，动词和宾语补足语之间缺少连接，"很怪"。）

**意译重组**：我打算把它涂成粉色。——「在宾语"它"前面加"把"字，引出被处置的对象；在宾语补足语"粉色"前加"成"字，标示涂漆的结果状态。」

**翻译公式**：`主语 + be going to + 动词 + 宾语 + 形容词（宾补）` → "主语 + 打算 + 把 + 宾语 + 动词 + 成 + 形容词"，英文的宾语补足语在中文中需用"把"字句 + "成"字来连接。

---

### This bookcase isn't for me.

**结构手术**：
- **This bookcase** → 主语（名词短语）→ [句首，被描述的对象] → 这个书架
- **isn't (is not)** → 谓语（be 动词否定式）→ [与单数主语搭配，否定] → 不是
- **for me** → 表语/状语（介词短语）→ [be 动词之后，说明主语的用途/归属] → 给我的/为我的

**词义还原**：
- **for**：此处不是表时间段的"for two hours"（持续），也不是表原因的"for this reason"（因为），而是表用途/归属——"为……而准备的、给……的"。for 在此限定了书架的归属关系。

**直译复盘**：这个书架不是为我的。（中文"不是为我的"可以理解但稍显生硬，不如"不是给我做的"自然。）

**意译重组**：这个书架不是给我做的。——「把介词 for 的"为/给"含义与上下文（制作书架的动作）结合，译为"给我做的"，将静态的归属关系转化为动态的动作目的。」

**翻译公式**：`主语 + be not + for + 人` → "主语 + 不是 + 给 + 人 + 做的/用的"，介词 for 表用途/归属时，中文常转化为"给……做的/用的"，将静态介词短语动态化。
