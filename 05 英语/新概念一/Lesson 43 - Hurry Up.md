# Lesson 43: How do you know Sam doesn't make the tea very often?
> https://nce.luzhenhua.cn/lesson.html#NCE1/043&044－Hurry%20Up

## 原文

Can you make the tea, Sam?

Yes, of course I can, Penny.

Is there any water in this kettle?

Yes, there is.

Where's the tea?

It's over there, behind the teapot.

Can you see it?

I can see the teapot, but I can't see the tea.

There it is!

It's in front of you!

Ah yes, I can see it now.

Where are the cups?

There are some in the cupboard.

Can you find them?

Yes. Here they are.

Hurry up, Sam!

The kettle's boiling!

## 句型结构

### "Can you + 动词原形?" — 礼貌请求

> 用情态动词 can 询问对方能力或请求对方做某事，语气比直接祈使句更礼貌

- `Can you make the tea?` — 你能泡茶吗？（请求）
- `Can you see it?` — 你能看到它吗？（询问能力）
- `Can you find them?` — 你能找到它们吗？（请求）
- 肯定回答：`Yes, of course I can.`（of course 加强肯定语气）
- 否定回答：`I can't see the tea.`（can't = can not）

**注意**：can 后面必须接动词原形，不能用 ~~can you to make~~ 或 ~~can you makes~~

### "Hurry up!" — 催促

> 固定搭配，用于催促他人加快速度

- `Hurry up, Sam!` — 快点，萨姆！
- 可接人名作呼语，也可单独使用

## 语法要点

### behind — 方位介词

> behind 表示"在……后面"，与已学的 [[Lesson 39 - Don't Drop It|in front of]]（在……前面）互为反义词

- `behind the teapot` — 在茶壶后面
- 同类方位介词：[[Lesson 35 - Our Village|beside]]（旁边）、[[Lesson 27 - Mrs. Smith's Living Room|near]]（附近）、between（之间）

**注意**：behind 是单个介词，而 in front of 是短语介词，不能省略 of（~~in front you~~）

### any 在疑问句 / some 在肯定句

> 疑问句中用 any、肯定句中用 some 表示"一些"，修饰不可数名词或复数名词

- `Is there any water...?` — 有水吗？（疑问句用 any）
- `There are some in the cupboard.` — 橱柜里有几个。（肯定句用 some）
- some 的用法详见 [[Lesson 27 - Mrs. Smith's Living Room]]

**注意**：any 也可用于否定句（如 I don't have any time），不可用于肯定句（~~I have any books~~）

## 语义分析

### Is there any water in this kettle?

**结构手术**：

- **Is** → 助动词（什么性质？）→ [置于句首，倒装在主语 there 之前，标志这是一个一般疑问句] → 是否存在
- **there** → 引导词，作形式主语（什么位置？）→ [跟在 is 后面，本身无实际指代，仅为句法结构服务，引出后面的真正主语] → 那里（这里不译出实际含义）
- **any** → 限定词（多少？）→ [修饰不可数名词 water，在疑问句中用 any（而非 some）表示"一些/任何"] → 任何/一些
- **water** → 不可数名词，作真正主语（什么东西？）→ [跟在限定词 any 之后，是 there be 句型的真正主语，表示存在的实体] → 水
- **in this kettle** → 介词短语，作地点状语（在哪里？）→ [介词 in（在……里面）+ 指示限定词 this（这个）+ 名词 kettle（水壶），放在句末修饰整个 there be 结构，限定存在的空间范围] → 在这个水壶里

整体结构：这是 **there be 句型** 的疑问形式，原序为 "There is any water in this kettle"，疑问时将 be 动词 is 提到句首。there 在此句中不表示"那里"，而是一个**语法占位词**——它占据主语位置，让真正的主语 water 能够放在 be 动词之后，形成"某处有某物"的存在句式。

**词义还原**：
- **there**：在这里不是地点副词"那里"，而是 there be 句型的**引导词**（也叫形式主语/expletive）。它不携带语义，纯粹为句法服务。你可以把它想象成舞台上拉开幕布的"工作人员"——幕布拉开后，真正的主角 water 才登场。
- **any**：限定词，在肯定句中意为"任何"，但在疑问句和否定句中**弱化为"一些"**的含义。疑问句中用 any 不表示"任何一个都行"，而是表示"是否存在一些"。
- **kettle**：名词，专指"电热水壶/烧水壶"，不是普通的壶（pot）或杯子（cup）。

**直译复盘**：是（有）任何水 在这个水壶里吗？（中文会把疑问动词"是否有"和地点"里"的位置调换，而且"任何水"在中文里听起来量级太大，"很怪"。）

**意译重组**：这个水壶里有水吗？「把地点状语 "in this kettle" 从句末挪到了句首作为话题框架，先说地点再说内容；把 "Is there...?" 的倒装疑问还原为中文正常的"……有……吗？"正序结构；将 "any" 从限定词降级翻译，中文里省略不译」。中文习惯"先定范围再问内容"——先说"水壶里"，再问"有水吗"，与英文的"有水在壶里吗？"语序正好相反。

**翻译公式**：there be 句型的疑问形式翻译时，将地点状语**话题化前移**到句首，形成"地点 + 有 + 某物 + 吗？"的结构：`Is there X in Y? → Y 里有 X 吗？`。疑问句中的 any 在翻译时通常省略，因为中文疑问句默认就包含"一些"的含义。

### I can see the teapot, but I can't see the tea.

**结构手术**：

- **I** → 人称代词，作主语（谁？）→ [放在情态动词 can 之前，是整个句子的动作执行者] → 我
- **can see** → 情态动词 + 实义动词，作谓语（做什么？）→ [can（能/可以）表示能力或可能性，see（看见）是实义动词，两者构成情态动词短语] → 能看见
- **the teapot** → 名词短语，作宾语（看见什么？）→ [定冠词 the + 名词 teapot，跟在 see 后面，是动作的直接承受者] → 茶壶
- **,** → 标点 → [将前后两个并列分句隔开]
- **but** → 并列连词（什么关系？）→ [连接前后两个结构对称的分句，表示转折/对比关系] → 但是
- **I can't see** → 人称代词 + 情态动词否定形式，作第二个分句的主语和谓语 → 我看不见（can't = can not，情态动词的否定直接在 can 后加 not）
- **the tea** → 名词短语，作第二个分句的宾语 → 茶叶

整体结构：这是由 **but 连接的并列复合句**（compound sentence），前后两个分句结构完全对称：`I + can(see) + 宾语`。第一句肯定（能看见茶壶），第二句否定（看不见茶叶），形成**视觉上的对比**——器物在场，内容物缺席，为后文"水壶正在烧水"的喜剧效果埋下伏笔。

**词义还原**：
- **see**：实义动词，"看见"——强调视觉感知的结果（有没有看到），而非看的过程（look at 强调动作方向，watch 强调持续关注）。"I can see" 不等于"我在看"，而是"我的视线范围内能看到"。
- **but**：并列连词，连接两个并列成分。注意 but 只连接**对等的结构**——这里连接两个完整的分句。不能说 ~~"I can see but tea"~~，因为前后结构不对称。
- **tea**：名词，在此语境中指"茶叶"（泡茶用的原料），而不是"一杯茶"（a cup of tea）或"茶水"。说话者看不到的是茶叶这种物质，暗示还没把茶叶放进去。

**直译复盘**：我能看见茶壶，但是我不能看见茶叶。（"不能看见"在中文里偏书面化，口语更自然地说"看不见"；且"茶叶"在中文需加上"叶"字才能准确传达原文语境，否则"茶"可能被理解为茶水，"很怪"。）

**意译重组**：我能看到茶壶，但看不到茶叶。「把 can't 的否定形式从 "can not" 的逐词翻译改为中文口语更自然的 "看不到"，让否定更紧密地附着在动词上；保持前后分句的并列结构不变，因为中英文的 but 连接用法一致」。这里中英文语序基本一致，无需大幅挪动。

**翻译公式**：情态动词 can 的否定缩写 can't 在翻译时，将否定意义**合并进动词**，译为"看不到/不能看/没法看"比"不能看到"更自然：`can't do X → 做不到X / 做不了X`。这是口语翻译中"否定内化"的常见技巧。

### The kettle's boiling!

**结构手术**：

- **The kettle** → 名词短语，作主语（什么东西？）→ [定冠词 the + 名词 kettle，放在谓语动词前，是动作的执行者] → 水壶
- **'s (is)** → be 动词（什么状态？）→ [缩写形式 's = is，与主语 kettle 搭配，构成现在进行时 be + doing 结构中的 be 部分] → 正在（表示状态或动作正在进行）
- **boiling** → 现在分词，作表语/构成进行时谓语（怎样？）→ [动词 boil 加 -ing 后缀，与 is 共同构成现在进行时，描述水壶当前的状态——水在沸腾] → 沸腾

整体结构：这是 **现在进行时**（present continuous）句型，`be (is) + 现在分词 (boiling)`。"The kettle's boiling" 存在两种理解角度：一是**主谓结构**（kettle 是 boiling 动作的发出者——水壶在沸腾）；二是**主系表结构**（boiling 作形容词性表语，描述 kettle 的状态——水壶处于沸腾状态）。从语义上讲，实际是"壶里的水在沸腾"，英语允许用容器（水壶）代替内容物（水）作主语，这是一种常见的**借代修辞**（synecdoche）——以容器指代内容。

**词义还原**：
- **boiling**：动词 boil 的现在分词，本义是"（液体）沸腾"。但在这里有双重含义：字面上说水壶在沸腾，实际意思是**壶里的水烧开了/水快开了**。英语中经常用容器的状态来借指内部液体的状态（如 "The pot is boiling" = 锅里的水在沸腾）。
- **kettle**：名词，"水壶/烧水壶"。注意 kettle 特指**带加热功能**的水壶（电热水壶或炉上烧水壶），不是保温瓶（thermos）或咖啡壶（coffee maker）。
- **The**：定冠词，在此表示**双方都知道的那个**——对话中只有一个水壶，听话者清楚指的是哪个。

**直译复盘**：水壶 正在沸腾！（中文会说"水壶里的水烧开了"，不会说"水壶在沸腾"。用容器直接当动作主语在中文里"很怪"。）

**意译重组**：水壶开了！「将借代修辞 "The kettle's boiling" 还原为中文习惯的容器+内容物结构——明确指出是壶里的水，而非壶本身；将 "boiling"（沸腾）简化为中文口语化的"开了"；去掉进行时的"正在"，因为中文"开了"本身已包含完成义」。中文不用容器做"沸腾"的主语，必须明确指出是"壶里的水"。

**翻译公式**：英语中容器（kettle, pot, pan）作主语搭配 cooking 类动词（boil, cook, fry）时，中文需**补充被省略的内容物**，用"容器 + 的 + 内容物"结构还原：`The kettle is boiling → 水壶（的水）开了`。这是英汉翻译中"借代还原"的典型操作。

### It's over there, behind the teapot.

**结构手术**：

- **It** → 代词，作主语（什么东西？）→ [放在 be 动词 is 之前，指代上文问到的对象——根据对话语境，指代茶/茶叶] → 它
- **'s (is)** → be 动词，作谓语（在哪里？）→ [缩写形式，与主语 it 搭配，用于说明主语的位置] → 在
- **over there** → 副词短语，作表语/方位成分（多远？）→ [副词 over（越过/那一边）+ 指示副词 there（那里），组合为固定方位短语，表示"在那边/在那里"，修饰位置] → 在那边
- **,** → 标点
- **behind the teapot** → 介词短语，作补充说明（具体哪里？）→ [介词 behind（在……后面）+ 定冠词 the + 名词 teapot（茶壶），对前面的 "over there" 做进一步的空间精确化] → 在茶壶后面

整体结构：这是由**逗号连接的两个并列方位成分**——"over there" 先给出一个大致方位（在那边），"behind the teapot" 再给出精确方位（茶壶后面）。两者之间不是主从关系，而是**"先粗后细"的递进说明关系**。中文正好相反——习惯先说精确位置再说大致方位，这构成了翻译时需要挪动的关键点。

**词义还原**：
- **over there**：副词短语，不是 "over"（上方）+ "there"（那里）的简单叠加，而是一个**习语化的固定搭配**，意为"在那边/在那里"，通常伴随手势指示方向。over 在这里起强调距离感的作用——比单独的 "there" 多一层"有一定距离"的暗示。
- **behind**：介词，"在……后面"。注意与 after 的区别：behind 指空间上的后方（茶壶后面），after 指时间或顺序上的在后（茶壶之后）。这里是空间关系，必须用 behind。
- **It**：代词，在此指代对话中被问到但还没找到的东西。根据前文 "I can't see the tea"，这里 It = the tea（茶叶）。

**直译复盘**：它在那边，在茶壶后面。（中文会说"就在茶壶后面"，不会先说"那边"再说具体位置，把精确信息放在了后面，"很怪"。）

**意译重组**：就在茶壶后面。「把精确方位 "behind the teapot" 从句末挪到句首作为主要信息；把粗略方位 "over there" 省略（中文口语中用"就"字代替，表示"就在不远的地方"）；在 "在" 前面加了"就"字，传达英文 over there 中"距离不远、很容易找到"的隐含语气」。中文的空间描述是**"先精确后粗略"**——先给出具体参照物（茶壶后面），再用语气词"就"暗示位置不远。英文则相反，是"先粗略后精确"。

**翻译公式**：当英文用逗号连接"粗略方位 + 精确方位"时，中文需**反转语序**，将精确方位前置、粗略方位用语气词（就、就在）替代：`It's over there, behind X → 就在 X 后面`。中文读者需要先"锚定"具体位置，再感受距离远近，与英文的导航逻辑相反。
