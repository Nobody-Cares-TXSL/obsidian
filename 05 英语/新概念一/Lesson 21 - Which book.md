# Lesson 21: Which book does the man want?
> https://nce.luzhenhua.cn/lesson.html#NCE1/021&022－Which%20Book

## 原文

Give me a book please, Jane.

Which book?

This one?

No, not that one. The red one.

This one?

Yes, please.

Here you are.

Thank you.

## 句型结构

### Give me a [noun], please.

> 祈使句请求，**Give me** + **a + 名词** + **please**，要求对方递东西。

- 完整形式，[[Lesson 3 - Sorry, sir.]] 的 `My [noun] please.` 是其省略版
- 可加形容词：`Give me the red book, please.`

**注意**：可数名词前不能省略冠词，~~Give me book~~ → `Give me a book.`

### Which [noun]?

> **Which** 用于在有限选项中指定"哪一个"，后面直接接名词。

- `Which book?` = 哪本书？（桌上有多本书时）
- 与 What 的区别：What 问"什么"（开放），Which 问"哪一个"（有限选择）

**注意**：Which 后的名词是单数还是复数取决于语境：`Which book?`（选一本）/ `Which books?`（选多本）

---

## 语法要点

### one 作代词

> **one** 代替前面提到过的可数名词单数，避免重复。复数用 **ones**。

- `This one?` = 这一本吗？（one = book）
- `The red one.` = 红色的那本。
- `Not that one.` = 不是那一本。

**注意**：one 只能代替可数名词，不能说 "I want red one" — 要加 the：`I want the red one.`

## 语义分析

### Give me a book please, Jane.

**结构手术**：
- **Give** → 谓语动词（祈使句动词原形？）→ [位于句首，无主语，是祈使句的标志] → 给
- **me** → 间接宾语（人称代词宾格？）→ [位于动词 Give 之后、直接宾语 a book 之前，采用双宾语结构] → 我
- **a book** → 直接宾语（名词短语？）→ [位于间接宾语 me 之后，由冠词 a + 名词组成] → 一本书
- **please** → 语气词（礼貌标记？）→ [句末，使请求更礼貌] → 请
- **Jane** → 呼语（独立成分？）→ [句末逗号隔开，不参与句法结构] → 简

**词义还原**：
- **Give me**：双宾语动词 give 接间接宾语（人）在前、直接宾语（物）在后，这是英语双宾结构的典型语序 `give sb. sth.`。中文习惯语序相同（给某人某物），所以这句翻译比较直接。

**直译复盘**：给我一本书请，简。（please 在句末、Jane 也在句末，中文里显得别扭。）

**意译重组**：简，请给我一本书。把呼语 Jane 挪到句首；把句末的 please 转化为句首的"请"。

**翻译公式**：`动词 + 间接宾语 + 直接宾语 + please, 呼语` → 中文重组为"呼语，请 + 动词 + 间接宾语 + 直接宾语"。中文语序：称呼 → 请 → 动作 → 对象。

---

### No, not that one. The red one.

**结构手术**：
- **No** → 否定回答（省略句？）→ [独立使用，替代完整否定句 "No, that is not the right one."] → 不
- **not that one** → 省略的否定句（省略了 be 动词？）→ [省略了主语和系动词，完整形式为 "That is not the one" 或 "(It is) not that one"] → 不是那一本
- **The red one** → 省略句（省略了系动词和表语？）→ [完整形式为 "(I want) the red one" 或 "(It is) the red one"，定冠词 the 表示特指] → 红色的那本
- **the** → 定冠词（特指？）→ [因双方都知道在说哪本"红色的"，前文提到过 the red book 的存在] → 那个

**词义还原**：
- **one**：代词，代替前文出现过的可数名词单数（这里 = book），避免重复说 "the red book"。
- **that**：指示代词，与 this 相对。此句中 "that one" 指对方手中或远处的那本，"this one" 指说话人近处的。

**直译复盘**：不，不是那个一。红色的那个一。（one 直译为"一"完全不通。）

**意译重组**：不，不是那一本。是红色的那本。把 one 翻译为量词"本"；补出省略的系动词"是"。

**翻译公式**：代词 one 代替可数名词时 → 翻译为相应的中文量词（本/个/只等），不可直译为"一"。`the + 形容词 + one` → "形容词的那 + 量词"。

---

### Here you are.

**结构手术**：
- **Here** → 地点副词（倒装引导词？）→ [位于句首，触发主谓倒装，正常语序为 You are here] → 这里
- **you** → 主语（代词？）→ [本应在 are 之前，但因 Here 倒装。注意：英语中代词不与 be 完全倒装，所以 you 仍在 are 之前] → 你
- **are** → 系动词（倒装？）→ [与 Here 构成局部倒装] → 是

**词义还原**：
- **Here you are**：作为固定惯用表达，已完全失去"你在这里"的字面含义，实际功能是"递东西给对方时说'给你'"。这是英语高频口语之一，类似于中文的"给"。

**直译复盘**：这里你是。（完全不通顺，因为倒装结构无法直译。）

**意译重组**：给你。将整个短语作为一个惯用语翻译，不拆分。

**翻译公式**：`Here you are` 是固定用法，在递东西场景中 → 统一译为"给你"。注意区分语境：递物时 = "给你"；到达目的地时（Here we are）= "我们到了"。
