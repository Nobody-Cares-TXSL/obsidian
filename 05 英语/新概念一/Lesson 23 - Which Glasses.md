# Lesson 23: Which glasses does the man want?
> https://nce.luzhenhua.cn/lesson.html#NCE1/023&024－Which%20Glasses

## 原文

Give me some glasses please, Jane.

Which glasses?

These glasses?

No, not those.

The ones on the shelf.

These?

Yes, please.

Here you are.

Thanks.

## 句型结构

### Give me some + 复数名词, please.

> 祈使句请求的复数版，用 **some** 代替 **a**，接复数可数名词。

- 单数：`Give me a book, please.`（[[Lesson 21 - Which book]]）
- 复数：`Give me some glasses, please.`
- `some` 也可用于不可数名词：`Give me some water, please.`

**注意**：`glasses` 是只有复数形式的名词，不能说 ~~a glasses~~，要说 `some glasses`

---

## 语法要点

### ones 作代词（复数）

> **ones** 是 **one** 的复数形式，代替前面提到过的可数名词复数，避免重复。[[Lesson 21 - Which book]] 讲了 one（单数），本课首次使用 ones。

- `The ones on the shelf.` = 架子上的那些（ones = glasses）
- `ones` 前可加限定词：`the ones`、`these ones`、`those ones`
- `ones` 后可接介词短语作后置定语：`The ones on the shelf`

**注意**：ones 只能代替可数名词复数，不能代替不可数名词

## 语义分析

### Give me some glasses please, Jane.

**结构手术**：
- **Give** → 谓语动词（祈使句动词原形？）→ [位于句首，无主语，祈使句标志] → 给
- **me** → 间接宾语（人称代词宾格？）→ [位于动词 Give 之后、直接宾语之前，双宾语结构中的"人"] → 我
- **some glasses** → 直接宾语（名词短语？）→ [some 为限定词（表示"一些"），glasses 为复数名词] → 一些眼镜
- **please** → 语气词（礼貌标记？）→ [句末，使请求更礼貌] → 请
- **Jane** → 呼语（独立成分？）→ [句末逗号隔开] → 简

**词义还原**：
- **some**：限定词，表示不确定数量"一些"。在肯定句中通常用 some，疑问句用 any。但这里是祈使句（请求），所以用 some 而非 any——因为说话者期待对方"给一些"，不是"零或一些"的疑问。
- **glasses**：名词 glass 作"玻璃"时不可数，但作"眼镜"时是**只有复数形式**的名词（pluralia tantum），永远带 -s。类似的有 scissors（剪刀）、pants（裤子）。不能说 ~~a glasses~~，只能用 `some glasses` 或 `a pair of glasses`。

**直译复盘**：给我一些眼镜请，简。（glasses 直译没问题，但 some glasses 中的"一些"在中文里可省略，直接说"眼镜"。）

**意译重组**：简，请给我拿些眼镜来。把呼语 Jane 挪到句首；把句末的 please 转化为句首的"请"；补出隐含的动词"拿……来"使中文更自然。

**翻译公式**：`Give me some + 复数名词, please` → "请给我拿些 X 来"。some 在中文请求语境中可译为"些"或省略；呼语和 please 都前移到句首。

### No, not those.

**结构手术**：
- **No** → 否定回答（省略句？）→ [独立使用，替代完整否定句] → 不
- **not those** → 省略的否定句（省略了主语和系动词？）→ [完整形式为 "(They are) not those (glasses)"] → 不是那些
- **those** → 指示代词（复数？）→ [those 是 this 的复数远指形式，此处代替 those glasses，指远处或对方手中的眼镜] → 那些

**词义还原**：
- **those**：this 的复数 + 远指形式，与 these（近指）相对。此句中直接用 those 而非 those ones，因为 those 本身已可独立充当代词指代复数名词。注意：those 可以单独用，但 this 通常不能单独作代词——要说 this one。

**直译复盘**：不，不是那些。（直译可以接受，但缺少"眼镜"这个被指代的名词让中文稍显突兀。）

**意译重组**：不，不是那些（眼镜）。补出被省略的名词"眼镜"使中文意思完整。

**翻译公式**：`not those` 这类指示代词单独出现的省略句 → 中文需要根据上下文补出被指代的名词，否则显得突兀。`not those/ones` → "不是那些 X"。

---

### The ones on the shelf.

**结构手术**：
- **The** → 定冠词（特指？）→ [修饰 ones，表示说话双方都知道是哪些] → 那些特定的
- **ones** → 代词（one 的复数？）→ [代替前文出现过的 glasses，避免重复。前面有 The 限定] → 那些（眼镜）
- **on the shelf** → 介词短语（后置定语？）→ [位于 ones 之后，修饰 ones，限定"在架子上的那些"] → 架子上的

**词义还原**：
- **ones**：one 的复数形式，代替前文提到的可数名词复数（此处 = glasses）。ones 前面必须有限定词（the / these / those），不能单独说 ~~the ones on shelf~~（必须加 the）。
- **on the shelf**：介词 on 表示"在……表面上"。shelf 意为"架子/搁板"，这里是名词作地点，the shelf 表示特指双方都知道的那个架子。

**直译复盘**：在架子上的那些一们。（ones 直译为"一们"完全不通；介词短语 on the shelf 放在后面修饰 ones 的后置定语结构在中文里也显得生硬。）

**意译重组**：架子上的那些（眼镜）。把原来在后面的介词短语 on the shelf（后置定语）挪到了前面，作为中文的前置定语"架子上的"；把 ones 翻译为量词"些"或直接省略。

**翻译公式**：英语的**后置定语**（介词短语/定语从句放在名词后面）→ 中文要挪到名词前面变成**前置定语**：`名词 + 介词短语` → "介词短语 + 的 + 名词"。`the ones on the shelf` → "架子上的那些"。这是英译中最常见的位移操作之一。
