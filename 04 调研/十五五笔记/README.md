# 十五五规划笔记

> [!abstract] 概述
> 《中华人民共和国国民经济和社会发展第十五个五年规划纲要》（2026-2030），于 2026 年 3 月 17 日正式发布。规划涵盖 18 篇内容，聚焦中国式现代化建设、高质量发展、科技自立自强等核心方向。
