# 终端环境配置总览

> 设备：ThinkPad E480
> 系统：Ubuntu 24.04.5 LTS / GNOME / X11
> 最近核验：2026-11-08

本文件只保留当前环境快照和专题入口。详细配置分别维护在独立文档中。

## 当前技术栈

| 层级 | 当前选择 | 版本 / 状态 |
|---|---|---|
| 桌面会话 | GNOME / X11 | Ubuntu 24.04.5 LTS |
| 终端模拟器 | Alacritty | 0.17.0，Cargo 安装 |
| Shell | Zsh | 5.9 |
| Shell 框架 | Oh My Zsh | 现役 |
| Prompt | Starship | 1.27.0 |
| 终端复用器 | tmux | 3.4 |
| 文件管理器 | Yazi | 26.9.1 |
| 图片叠加后端 | ueberzugpp | 2.9.11，X11 |
| 视频处理 | FFmpeg / ffprobe | 6.1.1 |
| 视频播放器 | VLC | 3.0.20 |

## 当前工作流结构

GNOME / X11
→ Alacritty 0.17.0
→ Zsh + Oh My Zsh + Starship
→ tmux（Session / Window / Pane / 工作区）
→ Yazi、lazygit、btop、编码 Agent 等 TUI / CLI 应用

这些层相互独立。更换终端模拟器不意味着必须更换 Shell、tmux 或 Yazi；评估替代工具时应一次只替换一层。

## 设备与资源约束

- CPU：Intel Core i5-8250U。
- 内存：约 7.6 GiB。
- GPU：Intel UHD Graphics 620 + AMD Radeon 540/550 系列。
- 桌面会话：X11。
- 机器资源有限；同时运行浏览器、IDE 和多个编码 Agent 时，应把内存占用、启动开销和响应延迟纳入选择。

## 当前关键结论

1. GNOME 的 Ctrl + Alt + T 已切换到 Cargo 安装的 Alacritty 0.17.0；系统 APT 版 0.13.2 仍保留。
2. tmux 负责会话、窗口、Pane 和工作区恢复；Alacritty 只负责终端窗口。
3. Yazi 的 GIF 使用原始动画预览；视频使用静态 3×3 Video Grid，Enter 交给 VLC 播放。
4. 当前图片预览走 X11 + ueberzugpp，不是 Kitty Graphics 原生协议。更换终端前必须在 tmux 内重新核验。
5. tmux 的 Prefix + z 已加入 Yazi 视频预览刷新逻辑，连续放大 / 还原已通过实际验收。
