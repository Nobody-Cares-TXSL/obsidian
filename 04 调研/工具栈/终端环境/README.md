## 文档职责

| 文档类型 | 应该记录 | 不应该塞入 |
|---|---|---|
| 环境总览 | 当前栈、组件关系、专题入口 | 每个配置项的全部细节 |
| 专题配置 | 单个工具的真实配置、依赖、行为 | 大量通用快捷键 |
| 快捷键速查 | 常用按键和操作结果 | 安装过程、长篇原理 |
| 维护决策 | 安装来源、风险、候选、回滚 | 重复抄写完整配置 |
| CLAUDE.md | AI 修改文档时必须遵守的规则 | 环境现状本身 |

## 状态标记

- **现役 / 已核验**：当前机器上确认存在并正在使用。
- **已安装 / 非主路径**：存在，但不是主要入口或当前工作流未依赖。
- **候选 / 未安装**：只用于未来评估。
- **停用 / 归档**：保留作回滚或历史参考，不参与当前运行。
- **待核实**：证据不足，不作确定结论。

## 维护规则

1. 以本机实际配置和命令输出为准，不以旧文档或记忆代替核验。
2. 修改一个工具时，只更新对应专题文档和必要的索引，不把内容重新塞回总览。
3. 版本、路径、启动入口发生变化时，更新核验日期。
4. 不记录密码、Token、私钥或其他秘密；只记录变量名、存储位置和风险。
5. 移动或重命名文档时，必须同步检查 README、CLAUDE.md、文档内部链接及整个 Obsidian 库中的入链。
