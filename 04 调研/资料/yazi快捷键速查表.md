**Yazi** 是一个基于 Rust 编写的终端文件管理器，以其极快的速度、异步 I/O 和丰富的功能（如内置图像预览）而闻名。为了帮助大家更高效地使用它，我根据官方文档整理了这份快捷键速查表。

## 🚀 核心速查表

这是一个横向对比表格，涵盖了日常使用 90% 的场景。

| ✅ 基本导航 | 📂 选择 & 打开 | ✂️ 文件操作 | 🧰 高级 & Tab |
| --- | --- | --- | --- |
| **`j`** / **`↓`** : 下移 | **`Space`** : 切换选中 | **`y`** : 复制 (Yank) | **`:`** / **`;`** : Shell 命令 |

## 📖 详细功能说明

如果你需要查看更详细的解释，请参考以下分类列表。

### 1\. 基本导航 (Basic Navigation)

- **`j`** 或 **`↓`** ：向下移动光标
- **`k`** 或 **`↑`** ：向上移动光标
- **`l`** 或 **`→`** ：进入当前选中的文件夹 / 进入目录
- **`h`** 或 **`←`** ：返回上级目录
- **`g`** `→` **`g`** ：移动到列表顶部
- **`G`** ：移动到列表底部

### 2\. 选择与打开 (Selection & Opening)

- **`Space`** (空格)：切换选中当前光标所在文件/目录
- **`v`** ：进入 Visual selection mode (开始可视选择)
- **`V`** ：退出 Visual selection mode 或取消选择模式
- **`Ctrl`** + **`a`** ：选中所有文件/目录
- **`Ctrl`** + **`r`** ：反选 (inverse selection) 所有文件/目录
- **`Enter`** 或 **`o`** ：打开当前/选中文件 或 进入目录

### 3\. 文件操作 (File Operations)

- **`y`** ：复制 (yank) 选中文件/目录
- **`x`** ：剪切 (cut) 选中文件/目录
- **`p`** ：粘贴 (paste) 之前复制/剪切的内容
- **`P`** ：粘贴并覆盖 (overwrite) (若目标已存在时)
- **`Y`** 或 **`X`** ：取消之前的复制/剪切状态
- **`d`** ：删除 (trash) 选中文件/目录 (移入回收站)
- **`D`** ：永久删除 (destroy) 选中文件/目录
- **`r`** ：重命名 (rename)
- **`a`** ：新建文件或目录 (输入名称以 `/` 结尾表示创建目录)
- **`.`**：切换隐藏文件显示/隐藏

### 4\. 高级功能 (Advanced)

- **`;`** 或 **`:`**：运行 Shell 命令 (`:` 会阻塞，直到命令结束)
- **`f`** ：过滤 / 搜索文件 (filter files)
- **`z`** / **`Z`** ：快速跳转 / 切换目录 (利用 fzf 或 zoxide)
- **`t`** ：新开一个 Tab (标签页)
- **`1-9`** ：切换到对应编号的 Tab
- **`[`** / **`]`** ：切换到 前一个 / 下一个 Tab

#### 路径复制组合键 (按 c 后接以下按键)

- **`c`** `→` **`c`** ：复制完整绝对路径
- **`c`** `→` **`d`** ：复制目录路径
- **`c`** `→` **`f`** ：复制文件名
- **`c`** `→` **`n`** ：复制不带扩展名的文件名

## 🔌 已装插件快捷键

以下为本机启用的 yazi 插件及其按键（绑定在 `~/.config/yazi/keymap.toml`）：

| 按键 | 插件 | 功能 |
| --- | --- | --- |
| **`c`** `→` **`m`** | chmod | 修改选中文件的权限（chmod） |
| **`T`** | toggle-pane | 最大化 / 还原预览面板 |
| **`+`** | zoom | 放大预览图片（每次 +1） |
| **`-`** | zoom | 缩小预览图片（每次 -1） |

> **git 插件**无按键绑定——它在文件列表的 linemode 中自动显示 Git 状态标记（`M` 修改、`?` 未跟踪、`D` 删除等）。

### 插件说明

| 插件 | 作用 |
| --- | --- |
| **git** | 文件列表显示 Git 状态（依赖 `init.lua` setup + `prepend_fetchers`） |
| **chmod** | 对选中文件执行 chmod |
| **toggle-pane** | 切换预览面板的显示/隐藏/最大化 |
| **zoom** | 放大缩小预览图片（**仅图片**，依赖 ImageMagick ≥ 7.1.1） |

## ⚙️ 本机配置要点

配置文件位于 `~/.config/yazi/`：

| 文件 | 内容 |
| --- | --- |
| `yazi.toml` | 主配置：`[mgr]`（显示隐藏文件/三栏比例/linemode=size）、`[preview]`（wrap=no/tab_size=4/max 1200×1200）、`[opener]`（VS Code 优先）、`[plugin]`（prepend_previewers + git fetchers） |
| `keymap.toml` | 插件按键绑定 |
| `init.lua` | git 插件初始化 |
| `package.toml` | 已装插件清单（`ya pkg` 管理） |

### 关键机制：`prepend_` vs 裸写

`[plugin]` 段的数组键有**三种语义**：

| 写法 | 效果 |
| --- | --- |
| `previewers = [...]` | **整体替换**预设的 22 条规则（丢失文件夹/字体/磁盘镜像等预览） |
| `prepend_previewers = [...]` | **前插**到预设规则之前（保留全部预设） |
| `append_previewers = [...]` | **后插**到预设规则之后（保留全部预设） |

同理适用于 `fetchers` / `preloaders` / `spotters`。**追加请用 `prepend_` 或 `append_`**。

### 预览依赖

| 用途 | 依赖 | 本机版本 |
| --- | --- | --- |
| 图片渲染（X11） | ueberzugpp | 2.9.10 ✅ |
| 视频缩略图 | ffmpeg + ffmpegthumbnailer | 6.1.1 ✅ |
| 备用字符渲染 | chafa | 1.14.0 ✅ |
| 图片缩放（zoom 插件） | ImageMagick | 6.9.12 ⚠️（zoom 要求 ≥ 7.1.1） |

> **GIF 动画**：yazi 目前**不支持**（官方 feature list #51 中 `GIFs images support` 未勾选）。GIF 会显示**静态首帧**。ueberzugpp 本身支持 GIF，但 yazi 只解码并发送第一帧。

### 插件管理命令

```bash
ya pkg add yazi-rs/plugins:<插件名>   # 安装插件
ya pkg list                          # 列出已装
ya pkg upgrade                       # 批量升级
ya pkg delete <插件名>               # 卸载
```
