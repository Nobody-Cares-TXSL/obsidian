# [盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)

## 题目
给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

## 题解

### 双指针

**思路**：左右指针分别指向数组首尾，每次向内移动短板指针。

- 初始化双指针分列容器左右两端
- 循环收窄：计算当前面积，更新最大值，移动短板指针
- 直到两指针相遇

**核心原理**：面积由短板决定。移动长板，面积一定变小；移动短板，面积才可能变大。

```java
class Solution {
    public int maxArea(int[] height) {
        int ans = 0;
        int left = 0;
        int right = height.length - 1;

        while (left < right) {
            // 面积 = 底边宽度 × 短板高度
            int temp = (right - left) * Math.min(height[left], height[right]);
            ans = Math.max(ans, temp);

            // 移动短板，才可能找到更大的面积
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return ans;
    }
}
```

**复杂度分析**

- 时间复杂度：O(n)，双指针遍历一次
- 空间复杂度：O(1)，只使用常数额外空间

## 关键要点

**核心洞察**

如果移动较高的指针：
- 宽度变小
- 高度由较矮的决定，移动较高的不会让高度增加
- 面积一定变小 

如果移动较矮的指针：
- 宽度变小
- 但高度可能变大（如果遇到更高的柱子）
- 面积可能变大 

**结论**：每次移动较矮的那个指针，才有可能找到更大的面积！
