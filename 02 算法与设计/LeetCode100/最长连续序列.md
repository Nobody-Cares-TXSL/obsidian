# [最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)

## 题目
给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

## 题解

### 排序（不满足题目要求， 自己写的o(╥﹏╥)o）
```java
class Solution {
    public int longestConsecutive(int[] nums) {
        int len = nums.length;
        // 边界处理：空数组直接返回 0
        if (len == 0) {
            return 0;
        }
        // 先排序，让连续的数字相邻
        Arrays.sort(nums);

        // length：当前连续序列的长度（增量）
        // lengthTemp：记录遇到过的最长连续序列长度（增量）
        int length = 0;
        int lengthTemp = 0;

        // 遍历排序后的数组，检查相邻元素
        for (int i = 0; i < len - 1; i++) {
            // 情况1：连续数字（后一个比前一个大 1）
            if (nums[i] + 1 == nums[i + 1]) {
                length++;  // 当前序列长度 +1
                // 更新最大值
                if (length > lengthTemp) {
                    lengthTemp = length;
                }
            } else {
                // 情况2：不连续时，需要判断是否为重复元素
                if (nums[i] != nums[i + 1]) {
                    // 不是重复元素，说明序列断开，重置当前长度
                    length = 0;
                }
                // 如果是重复元素（nums[i] == nums[i+1]），跳过，length 不变
            }
        }
        // lengthTemp 记录的是增量（边数），实际长度需要 +1
        // 例如：[1,2,3] 的 lengthTemp = 2，实际长度为 3
        return lengthTemp + 1;
    }
}
```
- **时间复杂度**： *O(n log n)**

### 哈希表

#### 核心思路

**基本思想**：对于每个元素 `x`，以 `x` 为起点不断查找 `x+1, x+2, ⋯` 是否存在，统计最长序列长度。

**关键优化：**

| 优化 | 作用 |
|:-----|:-----|
| **哈希集合** | 查找从 O(n) 降为 O(1) |
| **只从起点开始** | 若 `x-1` 存在则跳过 `x`，避免重复计算（从 `x-1` 开始的序列必然更长） |
| **遍历集合** | 避免重复元素导致超时（如 `[1,1,1,1,2,3]` 遍历数组会重复查找 1） |

#### 代码实现

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        // 构建哈希集合，实现 O(1) 查找
        Set<Integer> st = new HashSet<>();
        for (int num : nums) {
            st.add(num);
        }

        int ans = 0;

        // 遍历哈希集合（注意：不是遍历 nums）
        for (int x : st) {
            // 只从序列起点开始：x-1 存在说明 x 不是起点
            if (st.contains(x - 1)) {
                continue;
            }

            // x 是序列起点，往后查找连续序列
            int y = x + 1;
            while (st.contains(y)) {
                y++;
            }

            // 序列长度为 y - x
            ans = Math.max(ans, y - x);
        }

        return ans;
    }
}
```

#### 提前终止优化

**优化思路**：设 `m` 为哈希集合大小，当找到序列长度 `ans` 满足 `ans * 2 >= m` 时，剩余元素个数 `m - ans <= m/2 <= ans`，不可能组成更长序列，直接返回。

**优化版本代码：**

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> st = new HashSet<>();
        for (int num : nums) {
            st.add(num);
        }

        int m = st.size();  // 不同元素个数
        int ans = 0;

        for (int x : st) {
            if (st.contains(x - 1)) {
                continue;
            }

            int y = x + 1;
            while (st.contains(y)) {
                y++;
            }

            ans = Math.max(ans, y - x);

            // 提前终止：剩余元素不可能组成更长序列
            if (ans * 2 >= m) {
                break;
            }
        }

        return ans;
    }
}
```

- **空间复杂度**：O(n)
