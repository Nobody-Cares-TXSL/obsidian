# [移动零](https://leetcode.cn/problems/move-zeroes/)

## 题目
给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

## 题解

### 方法一：把 nums 当作栈

> 思路：
> - 用一个变量 `stackSize` 表示栈的大小（初始为 0）
> - 遍历数组，遇到非零元素则入栈（放入 `nums[stackSize]` 位置）
> - 遍历结束后，将剩余位置全部置为 0

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int stackSize = 0;
        for (int x : nums) {
            if (x != 0) {
                nums[stackSize++] = x; // 把 x 入栈
            }
        }
        Arrays.fill(nums, stackSize, nums.length, 0);
    }
}
```

> **Arrays.fill**：Java 工具方法，用于将数组指定范围内的元素全部设置为指定值。
> - 语法：`Arrays.fill(数组, 起始索引, 结束索引(不包含), 填充值)`
> - 示例：`Arrays.fill(nums, 2, 5, 0)` 将 nums[2] 到 nums[4] 全部置为 0

**复杂度分析**

- 时间复杂度：O(n)，其中 n 是 nums 的长度
- 空间复杂度：O(1)

### 方法二：双指针+交换元素

> 思路：
> - **左指针 `left`**：指向"下一个非零元素应该放的位置"，初始为 0
> - **右指针 `right`**：负责遍历整个数组寻找非零元素
> - 当 `right` 找到非零元素时，把它放到 `left` 的位置（交换），然后两个指针都前进一步
> - 如果 `right` 找到的是 0，只有 `right` 前进
> - 这样遍历一遍后，所有非零元素都按顺序移到了数组前面，0 自然都到了后面
>
> **举例** `nums = [0, 1, 0, 3, 12]`：
>
> | 步骤 | left | right | nums[left] | nums[right] | 操作 | 数组状态 |
> |:----:|:----:|:-----:|:---------:|:-----------:|:----:|:--------:|
> |  1   |  0   |   0   |     0     |      0      | 不交换，right++ | [0,1,0,3,12] |
> |  2   |  0   |   1   |     0     |      1      | 交换 -> left++,right++ | [1,0,0,3,12] |
> |  3   |  1   |   2   |     0     |      0      | 不交换，right++ | [1,0,0,3,12] |
> |  4   |  1   |   3   |     0     |      3      | 交换 -> left++,right++ | [1,3,0,0,12] |
> |  5   |  2   |   4   |     0     |      12     | 交换 -> left++,right++ | [1,3,12,0,0] |

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int left = 0;  // 下一个非零元素应该放的位置
        for (int right = 0; right < nums.length; right++) {
            if (nums[right] != 0) {
                // 交换 nums[left] 和 nums[right]
                int tmp = nums[right];
                nums[right] = nums[left];
                nums[left] = tmp;
                left++;
            }
        }
    }
}
```

**复杂度分析**

- 时间复杂度：O(n)，其中 n 是 nums 的长度
- 空间复杂度：O(1)

## 关键要点

> **双指针技巧**：维护一个指向"待填充位置"的指针，是处理原地修改数组的常用技巧。
