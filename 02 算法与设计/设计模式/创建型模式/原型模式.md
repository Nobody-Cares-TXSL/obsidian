# 原型模式

> 亦称：克隆、Clone、Prototype

## 意图

原型模式是一种**创建型设计模式**，使你能够复制已有对象，而又无需使代码依赖它们所属的类。

---

## 实现方式

### 基本原型模式

1. 创建**抽象原型类**，声明抽象的 `clone()` 方法。如果已有类层次结构，则只需在基类中添加该方法。

2. 为每个类定义一个**复制构造函数**（以同类对象为参数），该构造函数负责将参数对象的所有成员变量值复制到新对象中。

3. 在子类的复制构造函数中，首先调用 `super(target)` 来复制父类成员变量，然后再复制子类特有的成员变量。

4. 具体原型类实现 `clone()` 方法，通过复制构造函数创建并返回新对象：`return new ConcretePrototype(this);`。

### 原型注册站

1. 创建**原型注册表类**，内部使用 `HashMap<String, Prototype>` 存储预配置的原型对象。

2. 在构造函数中预先配置常用的原型对象，并为每个原型指定一个唯一的名称。

3. 提供 `get(String key)` 方法，该方法先从注册表中获取原型对象，然后调用其 `clone()` 方法返回副本。

4. 可选：提供 `put(String key, Prototype shape)` 方法，允许动态注册新的原型对象。

```java
// 克隆流程演示
Circle original = new Circle();
original.radius = 10;

// 调用 clone()
Circle cloned = original.clone();
    ↓
// 实际执行
return new Circle(this);
    ↓
// 进入复制构造函数
public Circle(Circle target) {  // target 就是 this（原对象）
    super(target);              // 复制父类字段
    this.radius = target.radius; // 复制自己的字段 = 10
}
    ↓
// 返回新对象（地址不同，数据相同）
```

## 优缺点

**优点：**

- 你可以克隆对象，而无需与它们所属的具体类相耦合
- 你可以克隆预生成原型，避免反复运行初始化代码
- 你可以更方便地生成复杂对象
- 你可以用继承以外的方式来处理复杂对象的不同配置

**缺点：**

- 克隆包含循环引用的复杂对象可能会非常麻烦

---

## 应用场景

- **复制对象而不依赖具体类**：当你需要复制一些对象，同时又希望代码独立于这些对象所属的具体类时
- **减少子类数量**：如果子类的区别仅在于其对象的初始化方式，可以使用该模式来减少子类的数量
- **处理第三方对象**：需要处理第三方代码通过接口传递过来的对象时

## 代码实现

### 实现方式一：基本原型模式

> 复制构造函数 + 抽象 `clone()` 方法，每个具体类实现自己的克隆逻辑

适合支持继承层次结构的多态克隆场景。

```java
// 抽象原型类
public abstract class Shape {
    public int x;
    public int y;
    public String color;

    // 常规构造函数
    public Shape() {
    }

    // 复制构造函数：使用已有对象的值初始化新对象
    public Shape(Shape target) {
        if (target != null) {
            this.x = target.x;
            this.y = target.y;
            this.color = target.color;
        }
    }

    // 抽象克隆方法
    public abstract Shape clone();

    @Override
    public boolean equals(Object object2) {
        if (!(object2 instanceof Shape)) return false;
        Shape shape2 = (Shape) object2;
        return shape2.x == x && shape2.y == y && Objects.equals(shape2.color, color);
    }
}

// 具体原型：Circle
public class Circle extends Shape {
    public int radius;

    public Circle() {
    }

    // 复制构造函数：先调用父类复制父类字段，再复制自己特有字段
    public Circle(Circle target) {
        super(target);  // 复制 x, y, color
        if (target != null) {
            this.radius = target.radius;  // 复制 radius
        }
    }

    @Override
    public Shape clone() {
        return new Circle(this);  // 通过复制构造函数创建副本
    }
}

// 具体原型：Rectangle
public class Rectangle extends Shape {
    public int width;
    public int height;

    public Rectangle() {
    }

    public Rectangle(Rectangle target) {
        super(target);
        if (target != null) {
            this.width = target.width;
            this.height = target.height;
        }
    }

    @Override
    public Shape clone() {
        return new Rectangle(this);
    }
}
```

**特点：**

- 实现简单，每个类独立管理自己的克隆逻辑
- 支持继承层次结构中的多态克隆
- 相同类的对象可以相互访问对方的私有成员变量

### 实现方式二：原型注册站

> 中心化注册表存储和管理原型对象，通过名称或其他参数获取克隆对象

适合需要预配置模板库的场景。

```java
// 原型工厂/注册站
public class BundledShapeCache {
    private Map<String, Shape> cache = new HashMap<>();

    // 构造函数：预加载原型对象
    public BundledShapeCache() {
        Circle circle = new Circle();
        circle.x = 5;
        circle.y = 7;
        circle.radius = 45;
        circle.color = "Green";

        Rectangle rectangle = new Rectangle();
        rectangle.x = 6;
        rectangle.y = 9;
        rectangle.width = 8;
        rectangle.height = 10;
        rectangle.color = "Blue";

        cache.put("Big green circle", circle);
        cache.put("Medium blue rectangle", rectangle);
    }

    // 动态添加原型
    public Shape put(String key, Shape shape) {
        cache.put(key, shape);
        return shape;
    }

    // 获取克隆对象（关键：返回 clone()，不是原对象）
    public Shape get(String key) {
        return cache.get(key).clone();
    }
}

// 客户端使用
public class Demo {
    public static void main(String[] args) {
        BundledShapeCache cache = new BundledShapeCache();

        Shape shape1 = cache.get("Big green circle");
        Shape shape2 = cache.get("Medium blue rectangle");
        Shape shape3 = cache.get("Medium blue rectangle");

        // shape2 和 shape3 是两个独立对象，但内容相同
        System.out.println(shape2 != shape3);  // true
        System.out.println(shape2.equals(shape3));  // true
    }
}
```

**特点：**

- 预配置常用对象，避免重复初始化代码
- 通过字符串 key 获取对象，使用方便
- 适合需要大量相似对象的场景（如游戏中的敌人、道具模板）

## 对比分析

| 对比项 | 基本原型模式 | 原型注册站 |
|:------:|:-------------------------|:---------------------|
| **实现复杂度** | ⭐ 简单 | ⭐⭐ 中等 |
| **对象获取方式** | 直接调用 `clone()` | 通过 `get(key)` 获取 |
| **原型管理** | 分散在各个类中 | 集中在注册表中 |
| **配置时机** | 每次使用时配置 | 预配置模板库 |
| **适用场景** | 简单对象克隆 | 需要预配置模板库 |
| **扩展性** | 需修改代码添加新原型 | 可动态注册新原型 |
| **线程安全** | 取决于实现 | 需考虑并发访问 |
| **典型应用** | 单一对象克隆 | 游戏对象模板、文档模板 |
