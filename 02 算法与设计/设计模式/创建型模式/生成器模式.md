# 生成器模式

> 亦称：建造者模式、Builder

## 意图

生成器模式是一种**创建型设计模式**，使你能够**分步骤创建复杂对象**。该模式允许你使用相同的创建代码生成不同类型和形式的对象。

---

## 实现方式

1. 声明**生成器接口**，定义所有构造步骤（`setPartA()`、`setPartB()` 等）。

2. 创建**具体生成器类**，实现构造步骤并提供获取产品的方法（`getResult()`）。不同生成器可生成不同类型的产品。

3. 定义**产品类**（可多种类型，无需共同接口）。

4. 创建**指导类**，封装常用构造流程的执行顺序。

5. 客户端将生成器传递给指导类，指导类调用构造步骤后，从生成器获取结果。

---

## 优缺点

**优点：**

- 你可以分步创建对象，暂缓创建步骤或递归运行创建步骤
- 生成不同形式的产品时，你可以复用相同的制造代码
- **单一职责原则**：你可以将复杂构造代码从产品的业务逻辑中分离出来

**缺点：**

- 由于该模式需要新增多个类，因此代码整体复杂程度会有所增加

---

## 应用场景

- **避免重叠构造函数**：当构造函数中有多个可选参数时，使用生成器模式让代码更简洁
- **创建不同形式的产品**：当你希望使用代码创建不同形式的产品（例如石头或木头房屋）时
- **构造组合树**：使用生成器构造组合树或其他复杂对象

---

## 代码实现

### 实现方式一：传统 Builder 模式（带指导类）

适合需要统一管理构造流程的场景，可以生成不同类型的产品。

```java
// 汽车类型枚举
enum CarType {
    CITY_CAR,   // 城市车
    SPORTS_CAR, // 跑车
    SUV         // SUV
}

// 产品类
class Car {
    private final CarType carType;
    private final int seats;
    private final double engineVolume;

    public Car(CarType carType, int seats, double engineVolume) {
        this.carType = carType;
        this.seats = seats;
        this.engineVolume = engineVolume;
    }

    public void print() {
        System.out.println("汽车: " + carType + ", " + seats + "座, " + engineVolume + "L");
    }
}

// 汽车手册（不同类型产品）
class CarManual {
    private final CarType carType;
    private final int seats;

    public CarManual(CarType carType, int seats) {
        this.carType = carType;
        this.seats = seats;
    }

    public void print() {
        System.out.println("手册: " + carType + ", " + seats + "座");
    }
}

// 生成器接口
interface Builder {
    void setCarType(CarType type);
    void setSeats(int seats);
    void setEngine(double volume);
}

// 汽车生成器
class CarBuilder implements Builder {
    private CarType carType;
    private int seats;
    private double engineVolume;

    public void setCarType(CarType type) { this.carType = type; }
    public void setSeats(int seats) { this.seats = seats; }
    public void setEngine(double volume) { this.engineVolume = volume; }

    public Car getResult() {
        return new Car(carType, seats, engineVolume);
    }
}

// 手册生成器
class CarManualBuilder implements Builder {
    private CarType carType;
    private int seats;

    public void setCarType(CarType type) { this.carType = type; }
    public void setSeats(int seats) { this.seats = seats; }
    public void setEngine(double volume) { /* 手册不需要引擎信息 */ }

    public CarManual getResult() {
        return new CarManual(carType, seats);
    }
}

// 指导类：封装构造流程
class Director {
    public void constructSportsCar(Builder builder) {
        builder.setCarType(CarType.SPORTS_CAR);
        builder.setSeats(2);
        builder.setEngine(3.0);
    }

    public void constructSUV(Builder builder) {
        builder.setCarType(CarType.SUV);
        builder.setSeats(5);
        builder.setEngine(2.5);
    }

    public void constructCityCar(Builder builder) {
        builder.setCarType(CarType.CITY_CAR);
        builder.setSeats(4);
        builder.setEngine(1.2);
    }
}

// 客户端
public class Demo {
    public static void main(String[] args) {
        Director director = new Director();

        // 制造汽车
        CarBuilder carBuilder = new CarBuilder();
        director.constructSportsCar(carBuilder);  // 指导类调用构造步骤
        carBuilder.getResult().print();           // 从生成器获取产品

        // 使用相同的步骤制造手册（不同类型的产品）
        CarManualBuilder manualBuilder = new CarManualBuilder();
        director.constructSportsCar(manualBuilder);  // 复用相同的构造流程
        manualBuilder.getResult().print();           // 获取手册产品
    }
}
```

**特点：**

- 指导类封装了构造流程，可以复用
- 生成器可以生成不同类型的产品（如汽车和手册）
- 构造步骤与具体产品解耦，灵活性强

### 实现方式二：流式 Builder（Builder 变体）

> Builder 模式的简化版，省略指导类，使用方法链调用。

适合简单对象创建，使用方法链式调用。

```java
// 汽车类型枚举（复用方式一的枚举）
enum CarType {
    CITY_CAR, SPORTS_CAR, SUV
}

// 产品类
class Car {
    private final CarType carType;
    private final int seats;
    private final double engineVolume;
    private final boolean hasGPS;

    private Car(Builder builder) {
        this.carType = builder.carType;
        this.seats = builder.seats;
        this.engineVolume = builder.engineVolume;
        this.hasGPS = builder.hasGPS;
    }

    public void print() {
        System.out.println("汽车: " + carType + ", " + seats + "座, " +
                         engineVolume + "L, GPS: " + hasGPS);
    }

    // 静态内部 Builder 类
    public static class Builder {
        private CarType carType = CarType.CITY_CAR;  // 默认值
        private int seats = 4;                        // 默认值
        private double engineVolume = 1.6;            // 默认值
        private boolean hasGPS = false;               // 默认值

        public Builder carType(CarType carType) {
            this.carType = carType;
            return this;
        }

        public Builder seats(int seats) {
            this.seats = seats;
            return this;
        }

        public Builder engine(double volume) {
            this.engineVolume = volume;
            return this;
        }

        public Builder gps(boolean hasGPS) {
            this.hasGPS = hasGPS;
            return this;
        }

        public Car build() {
            return new Car(this);
        }
    }
}

// 客户端
public class Demo {
    public static void main(String[] args) {
        // 使用默认值创建汽车
        new Car.Builder().build().print();

        // 跑车配置
        new Car.Builder()
                .carType(CarType.SPORTS_CAR)
                .seats(2)
                .engine(3.0)
                .gps(true)
                .build()
                .print();

        // SUV 配置
        new Car.Builder()
                .carType(CarType.SUV)
                .seats(5)
                .engine(2.5)
                .gps(true)
                .build()
                .print();
    }
}
```

**特点：**

- 代码简洁，使用方法链式调用
- 可以设置默认值，灵活配置
- 适合参数较多、但结构不复杂的场景

---

## 对比分析

| 对比项 | 传统 Builder（带指导类） | 流式 Builder（Builder 变体） |
|:------:|:-------------------------|:---------------------|
| **模式符合度** | ✅ 标准 GoF Builder 模式 | ⚠️ Builder 变体（省略 Director） |
| **适用场景** | 复杂对象、多产品类型、流程固定 | 单一产品、参数可选、灵活配置 |
| **构造流程** | 由指导类封装控制 | 客户端自由配置 |
| **角色数量** | Builder + Director + 产品 | Builder + 产品 |
| **产品类型** | 可生成不同类型产品 | 单一产品类型 |
| **方法链** | 不支持 | 支持 |
| **默认值** | 支持（在 Builder 中设置） | 支持（在 Builder 中设置） |
| **步骤复用** | 强（指导类封装常用流程） | 弱（客户端需重复调用） |
| **典型应用** | 汽车制造、文档生成 | 对象配置、AlertDialog、StringBuilder |
