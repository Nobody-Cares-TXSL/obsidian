# [寻找用户推荐人](https://leetcode.cn/problems/find-customer-referee/)

## 题目
表: `Customer`

| Column Name | Type    |
|-------------|---------|
| id          | int     |
| name        | varchar |
| referee_id  | int     |
在 SQL 中，id 是该表的主键列。
该表的每一行表示一个客户的 id、姓名以及推荐他们的客户的 id。

找出以下客户的姓名：

1. **被任何** `id != 2` 的用户推荐。
2. **没有被** 任何用户推荐。

以 **任意顺序** 返回结果表。

## 题解

```sql
-- 使用 IS NULL 判断没有被推荐的用户，OR 条件连接两种情况
SELECT name
FROM Customer
WHERE referee_id IS NULL OR referee_id != '2';
```

---

## SQL 流程

### 原始表

Customer 表

| id | name | referee_id |
|----|------|------------|
| 1  | Will | NULL       |
| 2  | Jane | NULL       |
| 3  | Alex | 2          |
| 4  | Bill | NULL       |
| 5  | Zack | 1          |
| 6  | Mark | 2          |

### WHERE referee_id IS NULL OR referee_id != 2

逐行检查（OR 只要有一个为真就保留）：

| id | name | referee_id | IS NULL? | != 2? | 保留? |
|----|------|------------|----------|-------|-------|
| 1  | Will | NULL       | 是       | —     | 保留 |
| 2  | Jane | NULL       | 是       | —     | 保留 |
| 3  | Alex | 2          | 否       | 否    | 丢弃 |
| 4  | Bill | NULL       | 是       | —     | 保留 |
| 5  | Zack | 1          | 否       | 是    | 保留 |
| 6  | Mark | 2          | 否       | 否    | 丢弃 |

> Alex 和 Mark 的 referee_id = 2，被 `!= 2` 排除。Will、Jane、Bill 的 referee_id 为 NULL，不能用 `!= 2` 判断（NULL 与任何值比较结果都是 NULL/未知），必须用 `IS NULL`。

### 最终结果

| name |
|------|
| Will |
| Jane |
| Bill |
| Zack |
