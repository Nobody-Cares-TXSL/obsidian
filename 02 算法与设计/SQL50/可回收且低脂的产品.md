# [可回收且低脂的产品](https://leetcode.cn/problems/recyclable-and-low-fat-products/)

## 题目

表：`Products`

| Column Name | Type    |
|-------------|---------|
| product_id  | int     |
| low_fats    | enum    |
| recyclable  | enum    |

`product_id` 是该表的主键（具有唯一值的列）。

- `low_fats` 是枚举类型，取值为以下两种 ('Y', 'N')，其中 'Y' 表示该产品是低脂产品，'N' 表示不是低脂产品。
- `recyclable` 是枚举类型，取值为以下两种 ('Y', 'N')，其中 'Y' 表示该产品可回收，而 'N' 表示不可回收。

编写解决方案找出既是低脂又是可回收的产品编号。

返回结果 **无顺序要求**。

## 题解

```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

---

## SQL 流程

### 原始表

Products 表

| product_id | low_fats | recyclable |
|------------|----------|------------|
| 0          | Y        | N          |
| 1          | Y        | Y          |
| 2          | N        | Y          |
| 3          | Y        | Y          |
| 4          | N        | N          |

### WHERE low_fats = 'Y' AND recyclable = 'Y'（同时满足两个条件）

| product_id | low_fats | recyclable |
|------------|----------|------------|
| 1          | Y        | Y          |
| 3          | Y        | Y          |

> AND 要求两个条件同时成立，product_id=0 可回收但非低脂，product_id=2 低脂但不可回收，都被过滤掉。
