# 回答评估与差距分析提示

## 回答评估

```
用户正在学习子话题「{subtopic}」，这是他们在该领域学习的第 {round} 轮问答。
他们的回答是：
"""
{user_answer}
"""

请基于源材料评估这个回答，按以下结构输出：

1. **正确的部分**：回答中准确描述的知识点
2. **不准确或遗漏的部分**：回答中错误或未提及的关键点
3. **补充洞见**：该子话题的 1-2 个进阶理解，帮助用户从"知道"升级到"理解"
4. **来源引用**：标注上述每条评估的具体来源依据

请用中文回答，语气鼓励但直接指出问题。不要说"你的回答很好"，直接给出评估。
```

## 差距分析

```
基于刚才 {round_count} 轮学习对话，请分析用户的学习状态：

1. **已掌握**：用户在哪些知识点上展现了扎实理解（列出具体表现）
2. **需加强**：用户在哪些方面存在理解偏差或知识空白（列出具体表现和对应的源材料章节）
3. **下一步建议**：推荐 2-3 个进一步深入学习的方向，附具体资源建议（来自源材料中的推荐或延伸阅读）

请用中文回答。
```
