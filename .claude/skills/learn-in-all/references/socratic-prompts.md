# 阶段 3：苏格拉底式问答循环 — 详细流程

> 回答评估和差距分析提示见 `references/evaluation-prompts.md`

## 3a. 知识全景提取

向 NotebookLM 发送全景提取提示：

```bash
notebooklm ask "基于所有源材料，请提取以下内容并结构化输出：1. 核心概念（5-8个，每个一句话定义，用[[双链]]标注）2. 主要争议（2-3个，列出正反方）3. 演进时间线（关键里程碑）4. 入门学习路径（子主题列表，标注难度和依赖）。用中文回答。" -s {source_id_1} -s {source_id_2} --notebook {notebook_id}
```

> 如用户选择了部分源材料，使用 `-s` 参数指定选中的 source_id；如全选则不加 `-s`。

将 NotebookLM 的返回结果**原样展示**给用户，不做二次加工或格式化。

### 全景提取提示（独立使用）

```
基于所有源材料，请提取以下内容并结构化输出：

1. **核心概念**（5-8个）：每个概念用一句话定义，标注概念之间的关系
2. **主要争议**（2-3个）：列出正反双方的核心论点
3. **演进时间线**：按时间排序的关键里程碑，标注每个里程碑的意义
4. **入门学习路径**：按优先级排序的子主题列表，每个子主题标注难度等级（入门/中级/高级）和前置依赖

请用中文回答，保持简洁。对每个核心概念名加上 [[双链]] 格式标注。
```

## 3b. 渐进式问答（不限轮数）

按知识地图中的学习路径子主题顺序推进。每个子主题执行循环：

### 出题

根据子主题位置选择难度：
- 前 1-2 个 → **概念理解型**（入门）
- 中间 → **原理解释型 / 对比分析型**（中级）
- 最后 1-2 个 → **批判思考型**（高级）

使用下方对应的出题提示，让 NotebookLM 生成问题。

### 提问

通过 `AskUserQuestion` 向用户展示问题，提供选项：
- 用户自由回答（选择"Other"输入）
- "跳过此主题"
- "结束学习"

### 评估

使用 `evaluation-prompts.md` 中的回答评估提示，发送用户回答给 NotebookLM 评估。

### 判断

展示评估结果后：
- **覆盖核心要点** → 进入下一子主题
- **有明显遗漏** → 同一子主题换角度追问
- 用户主动选择"已理解" → 进入下一子主题

## 出题提示模板

### 概念理解型（入门）

```
请基于源材料，为子话题「{subtopic}」生成一道开放性问题：
- 要求：测试对该子话题核心定义和基本原理的理解
- 形式：开放式问题，不是选择题或判断题
- 难度：入门级，适合初次接触该概念的学习者
- 语言：中文
- 问题应该能区分"了解表面"和"真正理解"的学习者
```

### 原理解释型（中级）

```
请基于源材料，为子话题「{subtopic}」生成一道开放性问题：
- 要求：要求回答者解释"为什么"和"怎么做"，测试对内在原理的深入理解
- 形式：开放式问题，需要推理和分析
- 难度：中级，假设回答者已掌握基本定义
- 语言：中文
- 避免简单的事实回忆，聚焦于因果逻辑和机制解释
```

### 对比分析型（中级-高级）

```
请基于源材料，为子话题「{subtopic}」生成一道开放性问题：
- 要求：让回答者比较、对比或关联该领域的多个概念/方法/流派
- 形式：开放式问题，需要横向思维
- 难度：中高级
- 语言：中文
- 问题应迫使回答者展现对概念间异同的理解
```

### 批判思考型（高级）

```
请基于源材料，为子话题「{subtopic}」生成一道开放性问题：
- 要求：给出一个具体场景或现实问题，让回答者判断该用什么方法、为什么，或指出某个观点的局限性
- 形式：开放式问题，需要批判性思维和实际应用能力
- 难度：高级
- 语言：中文
- 问题应没有标准答案，测试回答者的独立思考能力
```

## 结构化笔记生成提示（阶段 4 使用）

```
基于我们的全部对话和源材料，请生成一份用于 Obsidian 的 Markdown 学习笔记。

要求：
1. YAML frontmatter，包含：title（{domain} 领域学习）、tags（领域学习、{domain_tag}）、date（今天的日期）
2. 提取 5-8 个核心概念，每个用 [[概念名]] 的双链格式标注
3. 整理"理论演进脉络"（用 mermaid timeline 图表）和"核心争议"（用表格对比正反方）
4. 总结推荐的学习路径（按子主题排序，标注难度和依赖）
5. 整理苏格拉底问答中的关键收获（每个子主题一句话要点）
6. 列出知识差距和进一步学习建议
7. 在文末附上来源列表（编号表格，标注类型：PDF/URL/调研）
8. 使用 Obsidian callout 语法（> [!abstract]、> [!info]、> [!warning] 等）
9. 使用中文
```
