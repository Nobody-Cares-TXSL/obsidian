# [字母异位词分组](https://leetcode.cn/problems/group-anagrams/)

## 题目
给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

> 字母异位词: 如果两个字符串从小到大排序后相等，那么两个字符串就互为字母异位词，否则不是。

## 题解

### 哈希表

> 思路:
> 输入 `strs=[eat,tea,tan,ate,nat,bat]`。
> 每个字符串各自排序，得到 `aet,aet,ant,aet,ant,abt`。
> 
> 排序后是 `aet` 的字符串，排序前是 `eat,tea,ate`。
> 排序后是 `ant` 的字符串，排序前是 `tan,nat`。
> 排序后是 `abt` 的字符串，排序前是 `bat`。
> 
> 用哈希表分组，把排序后的字符串当作哈希表的 key，排序前的字符串加到对应Key的Value列表中。(Value 列表则是结果列表)

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> hashMap = new HashMap<>();
        for (String s : strs) {
            // 将字符串转换为字符数组
            char[] sorteds = s.toCharArray();
            // 排序
            Arrays.sort(sorteds);
            String key = new String(sorteds);
            if (!hashMap.containsKey(key)) {
                // 哈希表中不存在则添加： Key:key
                hashMap.put(key, new ArrayList<>());
            }
            // 增加对应Key的Value
            hashMap.get(key).add(s);
        }
        return new ArrayList<>(hashMap.values());
    }
}
```

**复杂度分析**

- 时间复杂度：O(nklog k)，其中 n 是字符串数量，k 是字符串最大长度。需要对每个字符串排序。
- 空间复杂度：O(nk)，其中 n 是字符串数量，k 是字符串最大长度。主要为哈希表的开销。

也可更加优雅的用 `hashMap.computeIfAbsent(key, _ -> new ArrayList<>()).add(s);`

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> hashMap = new HashMap<>();
        for (String s : strs) {
            // 将字符串转换为字符数组
            char[] sorteds = s.toCharArray();
            // 排序
            Arrays.sort(sorteds);
            hashMap.computeIfAbsent(new String(sorteds), _ -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(hashMap.values());
    }
}
```

**复杂度分析**

- 时间复杂度：O(nklog k)，其中 n 是字符串数量，k 是字符串最大长度。需要对每个字符串排序。
- 空间复杂度：O(nk)，其中 n 是字符串数量，k 是字符串最大长度。主要为哈希表的开销。
> computeIfAbsent(K key, Function<K, V>) --> V
> - 检查K是否存在，存在则直接返回已有的List, 不存在则执行Function

**Java Stream 形式**
```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        return new ArrayList<>(
            Arrays.stream(strs)                    // 1. 将字符串数组转为 Stream 流
                  .collect(Collectors.groupingBy(s -> { // 2. 按照分类函数进行分组
                      char[] sortedS = s.toCharArray(); // 2a. 将字符串转换为字符数组
                      Arrays.sort(sortedS);            // 2b. 对字符数组排序（字母异位词排序后相同）
                      return new String(sortedS);      // 2c. 将排序后的字符数组转回字符串作为 key
                  }))                                // 结果：Map<排序后字符串, 原始字符串列表>
                  .values()                           // 3. 取 Map 的所有 value（分组后的列表）
        );                                          // 4. 将 Collection 转为 ArrayList 返回
    }
}
```

**复杂度分析**

- 时间复杂度：O(nklog k)，其中 n 是字符串数量，k 是字符串最大长度。需要对每个字符串排序。
- 空间复杂度：O(nk)，其中 n 是字符串数量，k 是字符串最大长度。主要为哈希表的开销。

> `Collectors.groupingBy(Function<T, K>)` --> `Map<K, List<T>>`
> - **作用**：按分类函数将元素分组成 `Map<K, List<T>>`

**图示**
```
输入:    ["eat", "tea", "tan", "ate", "nat", "bat"]
              ↓
        对每个字符串内部排序
              ↓
中间结果: ["aet", "aet", "ant", "aet", "ant", "abt"]
              ↓
        按排序后的字符串分组
              ↓
输出: {
       "aet" -> ["eat", "tea", "ate"],
       "ant" -> ["tan", "nat"],
       "abt" -> ["bat"]
     }
```

> **关键理解**：
> - **Key**：排序后的字符串（所有字母异位词排序后都相同）
> - **Value**：原始字符串列表（排序前的字符串）
